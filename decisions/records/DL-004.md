## Context

The sync map (DL-003) is needed in two places: at build time in Node, for sites that prebuild maps for their pages, and in the browser, for sites that just point the player at the exported files. The core is also what other tools (a CLI, a converter service) would build on.

## Decision

The core (`src/core`, published as `segno/core`) has **no runtime dependencies** and **uses no DOM or Node APIs**. It works on strings and plain data only, and runs unchanged in Node 22+ and evergreen browsers.

The build compiles the core against the ES2023 library alone (no `dom` lib in `tsconfig.build.json`), so a DOM API used by mistake fails the build.

## Rationale

- One implementation for build time and the browser, with no environment shims.
- No dependencies means no supply-chain exposure, no version conflicts for users, and a small download (about 3 KB gzipped, unminified).
- Parsing a flat format and binary searching sorted times need no library.

## Consequences

- Small helpers (the attribute parser, the viewBox reader) are written and tested here instead of imported.
- Anything that needs the DOM (fetching files, drawing markers, audio) belongs in the player, not the core.
