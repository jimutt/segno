## Context

Segno should be easy to adopt on any site, in any product, and easy to contribute to. Its licence decides both.

A copyleft licence, the GPL version 3, was considered: it would keep derivatives open, including closed-source commercial products built on Segno. It was rejected for two reasons:

- It discourages adoption in closed-source software, which is a large part of where a score player would be used.
- It works against outside contributions. Contributors keep the copyright in what they contribute, so once a GPL project has accepted contributions, nobody, the maintainer included, can use the combined code under other terms (for example in a closed-source product) without a contributor licence agreement from everyone. Asking for such agreements is a barrier to contributing.

MuseScore itself is `GPL-3.0-only`. Segno contains no MuseScore code: it reads files MuseScore writes, so MuseScore's licence doesn't extend to it.

## Decision

- Everything in the repository is licensed **MIT**, with the licence text in `LICENSE` (copyright "The Segno contributors").
- Contributions are accepted under the same licence (inbound = outbound), with no contributor licence agreement.
- Every source file starts with an SPDX header, a copyright line and a link to the repository:

  ```ts
  // SPDX-License-Identifier: MIT
  // Copyright (C) 2026 The Segno contributors
  // https://github.com/jimutt/segno
  ```

  `scripts/check-spdx.mjs` checks the first line in CI. The headers keep the licence and the source attached to each file when it is copied or bundled on its own. A browser bundle, when there is one, starts with the same notice.

## Rationale

MIT lets anyone use, modify and redistribute Segno, in open or closed software, with only the notice kept. Because contributions come in under the same terms, everyone, the maintainer included, can use all of the code on those terms, and nobody needs to sign anything to contribute. It is also the most common licence in the npm ecosystem, so users and their legal reviews already know it.

## Consequences

- Closed-source products may build on Segno without sharing their changes; that is accepted as the cost of easy adoption.
- MuseScore code must never be copied into Segno: it is GPL-licensed, and including it would make Segno's combined code GPL. Segno's knowledge of MuseScore's files comes from the documented behaviour of its exports, and any reading of MuseScore's source to understand a file format must not turn into copied code.
- Contributions are licensed MIT by the act of contributing (stated in CONTRIBUTING.md).
