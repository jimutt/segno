## Context

A player needs, for a score: where each bar is on its page, which bar plays when, and optionally where each note is and when it plays. The raw position files (DL-002) are in MuseScore's units, need the pages' sizes to be useful, and are around ten times larger than the data they carry. A site may want to compute this once at build time and embed it in a page, compute it in the browser, or receive it from another tool or service.

## Decision

`buildSync()` produces a **sync map**, plain JSON, format version 1:

```json
{
  "v": 1,
  "bars": [[0, 0.11309, 0.15675, 0.14102, 0.14543]],
  "events": [[0, 0], [1, 652]],
  "notes": [[0, 0.1901, 0.15675, 0.14543]],
  "noteEvents": [[0, 0], [1, 326]]
}
```

- `bars`: one `[page, x, y, w, h]` per bar, in score order.
- `events`: `[barIndex, ms]` in playback order.
- `notes` and `noteEvents`, only when an `.spos` was given: one `[page, x, y, h]` per note/rest position, x at the noteheads' centre and y/h the system; `[noteIndex, ms]` in playback order.

All positions are fractions of the page (0–1), rounded to 5 decimals. Entries are positional arrays (tuples), not objects.

The format is versioned by `v`. The version changes whenever a reader of the old version would misread the new data (a field removed, renamed or changed in meaning); adding an optional field that older readers can ignore keeps it. Readers should reject a version they don't know.

The format is documented for other producers in `docs/sync-map.md`.

## Rationale

- Fractions of the page let a player show pages at any size and place markers in percentages; no page sizes are needed at play time.
- Tuples keep a typical song's map around 2 KB, small enough to embed in every page that shows a score.
- 5 decimals is a hundred-thousandth of the page (about 3 µm on A4), far below what a screen shows.
- A documented, versioned JSON format lets a build step, the browser, or a separate service (DL-001) produce maps, and lets the player accept prebuilt ones.

## Consequences

- Tuples are less self-describing than objects; the TypeScript types (`Bar`, `Note`, `TimedEvent`, `SyncMap`) and the format document name each position.
- Changing the meaning of a field means a version 2 and keeping version 1 readable for as long as maps in the wild use it.
